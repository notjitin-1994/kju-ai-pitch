# Impeccable Skill

## Overview
An open-source design skill framework that gives AI assistants designer vocabulary for beautiful UI and prevents generic design output. Built by Paul Bakaus.

## Purpose
Brings curated frontend design expertise to AI coding harnesses. It provides a shared language between humans and AI for communicating design intent without leaving the coding environment.

## Key Features

### 17 Invokable Design Commands
1. polish - Enhance visual quality
2. audit - Review design quality
3. simplify - Reduce complexity
4. redesign - Bold interface changes
5. enhance - Improve specific elements
6. refactor - Restructure design
7. check - Validate design patterns
8. optimize - Improve performance
9. improve - Incremental improvements
10. fix - Address design issues
11. review - Comprehensive review
12. init - Initialize project context
13. create - Generate new designs
14. build - Construct components
15. plan - Design strategy
16. implement - Execute design plans
17. validate - Verify design compliance

### Design Domains Covered
- Typography
- Color systems
- Layout patterns
- Motion & animation
- Spacing & rhythm
- Component patterns
- Anti-patterns
- Accessibility
- Responsive design

### Supported Tools
- Cursor
- Claude Code
- GitHub Copilot
- Gemini CLI
- Codex CLI

## Installation
```
/impeccable init     # Establish project context
/impeccable polish   # Improve existing interfaces
```

## Core Concept
AI frontends share one look with no words for hierarchy, contrast, or restraint. Impeccable gives your agent the designer's vocabulary and you the same commands, so you both stop guessing and start directing.
